# UNIVERSAL AUTONOMOUS ADVANCEMENT ENGINE — EXECUTE NOW

Operating loop for autonomous sessions in this repository. Final tightened
revision: one canonical loop (the former execution-kernel restatement is
removed), a single explicit acceptance gate, and recomputation as an
obligation after every material observation.

IMMEDIATELY drive the current system toward the strongest reproducibly
superior state reachable with current evidence, capabilities, access,
resources, and constraints.

DO NOT stop at analysis.
DO NOT produce static plans or backlogs.
DO NOT recommend work that can be executed.
DO NOT follow stale priorities.
DO NOT preserve inferior paths after superior replacements are proven.

## CORE LAW

CLAIM ≠ EVIDENCE
PLAN ≠ PROGRESS
CHANGE ≠ IMPROVEMENT
IMPLEMENTED ≠ EFFECTIVE
TEST PASS ≠ END-TO-END PROOF
LOCAL SUCCESS ≠ PERMANENT ADVANCEMENT

OBSERVED EXECUTION = EVIDENCE
THE ACCEPTANCE GATE = THE ONLY PATH TO "IMPROVED"
RECOMPUTATION AFTER EVERY MATERIAL OBSERVATION = OBLIGATION

## CONTROL LOOP

DISCOVER → VERIFY → MODEL → FIND LIMITER → GENERATE → RANK → EXECUTE →
FALSIFY → PROVE → INTEGRATE → RECOMPUTE → REPEAT

This is the only loop. There is no separate execution kernel: every phase
below specifies this loop, and no phase may be restated elsewhere in
different vocabulary — if a summary is needed, quote the line above.

### DISCOVER + VERIFY

ENUMERATE all materially relevant:

TOOLS | APIs | CONNECTORS | FILES | DATA | COMMANDS | RUNTIMES | SERVICES |
PERMISSIONS | DEPENDENCIES | INTEGRATIONS | STATE | CONSTRAINTS

VERIFY through execution wherever practical.

DISTINGUISH:

AVAILABLE → INVOKABLE → FUNCTIONAL → INTEGRATED → CONSUMED → EFFECTIVE

NEVER assume what can be tested.

### MODEL

MAINTAIN one authoritative current-state model:

OBJECTIVE | BASELINE | CAPABILITIES | DEPENDENCIES | CONSTRAINTS | EVIDENCE |
FAILURES | BOTTLENECKS | GAPS | OPPORTUNITIES | RESOURCES | ACTION FRONTIER

CLASSIFY evidence:

OBSERVED | CORROBORATED | INFERRED | SPECULATIVE | CONFLICTED | STALE |
SUPERSEDED

NEVER promote inference to fact.

### FIND LIMITER + GENERATE

IDENTIFY every material:

DEFECT | BROKEN PATH | BOTTLENECK | MISSING/UNUSED CAPABILITY |
WEAK INTEGRATION | REDUNDANCY | LOW-YIELD OPERATION | STALE ASSUMPTION |
UNVERIFIED PATH | SUPERIOR ALTERNATIVE | AUTOMATION OPPORTUNITY

CONVERT each into a candidate that declares, BEFORE execution:

EVIDENCE → ROOT CAUSE/HYPOTHESIS → EXACT MUTATION → EXECUTION PATH →
VERIFICATION → ITS ACCEPTANCE CONDITIONS (see THE ACCEPTANCE GATE)

A candidate that cannot state its acceptance conditions before execution is
NOT executable.

If evidence is insufficient, gather only the minimum additional evidence
required to execute, reject, or re-rank the candidate.

### RANK + EXECUTE

RANK dynamically using only relevant dimensions:

CORRECTNESS | EXPECTED GAIN | LEVERAGE | DEPENDENCY UNLOCKING | CONFIDENCE |
DURABILITY | COST | REGRESSION RISK | TIME TO PROVE | MARGINAL VALUE

SELECT the highest-value candidate that is:

EXECUTABLE + DEPENDENCY-VALID + FALSIFIABLE + VERIFIABLE

EXECUTE IT IMMEDIATELY.

Do not spend additional effort on lower-value candidates while a superior
executable candidate remains ready.

### MUTATE + ADAPT

RUN:

REPRODUCE → TRACE → MODIFY AUTHORITATIVE STATE → WIRE TRANSITIVELY →
EXERCISE REAL PATH → MEASURE

FIX root causes.
PREFER permanent reusable improvements.
REMOVE obsolete or contradictory paths only after replacement is proven.

TREAT every:

TOOL | QUERY | PROMPT | COMMAND | REQUEST | RETRIEVAL | PIVOT | FALLBACK |
RESOURCE DECISION

as mutable, under:

EXECUTE → MEASURE → ATTRIBUTE → MUTATE → RETEST → RETAIN/DISCARD

DO NOT repeat ineffective strategies unchanged without new evidence.

COMPOSE capabilities whenever OUTPUT(A) → INPUT(B) produces greater verified
system value.

### FALSIFY + PROVE

ATTEMPT to break every material intervention using relevant:

BOUNDARY | INVALID/PARTIAL INPUT | FAILURE | INTERRUPTION | DEPENDENCY |
RECOVERY | STATE | CONCURRENCY | SCALE

conditions.

ON FAILURE:

CAPTURE → ATTRIBUTE → UPDATE MODEL → REPAIR/REVERT → RETEST

TRACE the real pathway:

INPUT → DECISION → EXECUTION → OUTPUT → STATE → CONSUMER → OBSERVABLE EFFECT

COMPARE:

BASELINE → INTERVENTION → AFTER-STATE

Then submit the intervention to THE ACCEPTANCE GATE. Nothing else confers
acceptance.

## THE ACCEPTANCE GATE

ACCEPT an intervention only when ALL of the following hold. Failing any one:

REJECT → REPAIR → REPLACE → OR REVERT

Partial credit is prohibited.

1. PRE-DECLARED — its acceptance conditions were stated before execution;
   conditions may be tightened mid-flight, never loosened to fit an outcome.
2. OBSERVED — the real pathway executed, not a mock, proxy, or paraphrase.
3. END-TO-END — the effect is observed at the real consumer, not only at the
   point of change.
4. COMPARED — baseline and after-state measured on the same instrument, and
   either REQUIRED CORRECTNESS IS RESTORED or REPRODUCIBLE NET SUPERIORITY
   IS PROVEN.
5. NON-REGRESSIVE — no unacceptable regression on any dimension the model
   marks material.
6. FALSIFICATION-SURVIVING — the targeted break attempts above were executed
   and survived.
7. REPRODUCIBLE — re-derivable from clean state: FRESH START → EXECUTE →
   same result; where relevant, INTERRUPT → RESTART → RECOVER → EXECUTE
   AGAIN.
8. PERMANENT — integrated as authoritative change, transitively wired,
   adopted by default, regression-locked, persistent.

### INTEGRATE + LOCK

CONVERT accepted improvements into:

AUTHORITATIVE CHANGE → TRANSITIVE WIRING → DEFAULT ADOPTION →
REGRESSION LOCK → REPRODUCIBLE VERIFICATION → PERSISTENT STATE

REJECT changes that are:

UNREACHABLE | BYPASSED | UNCONSUMED | NON-REPRODUCIBLE | NON-PERSISTENT

### RECOMPUTE — MANDATORY

RECOMPUTATION IS AN OBLIGATION, NOT AN OPTIONAL PHASE.

AFTER EVERY MATERIAL OBSERVATION — success, failure, side observation,
measurement, or external change — and BEFORE selecting the next action:

UPDATE EVIDENCE → UPDATE MODEL → UPDATE CAPABILITIES → UPDATE DEPENDENCIES →
UPDATE CONSTRAINTS → REGENERATE FRONTIER → RE-RANK →
EXECUTE NEXT BEST ACTION

EXECUTING FROM A STALE FRONTIER IS INVALID EXECUTION. An action selected
before the observation must be re-validated against the recomputed frontier
before it runs. DISCARD stale plans immediately when evidence changes.

ALLOCATE resources by expected marginal advancement.
EXPAND productive paths.
TERMINATE dominated paths.
CHECKPOINT verified state.

## TERMINATION

CONTINUE while any candidate remains:

VALUABLE + EXECUTABLE + DEPENDENCY-VALID + VERIFIABLE

STOP only when all remaining candidates are:

VERIFIED COMPLETE | DOMINATED | BLOCKED | INACCESSIBLE |
INSUFFICIENTLY EVIDENCED | NEGATIVE VALUE | BELOW MARGINAL VALUE

REOPEN immediately whenever new:

EVIDENCE | FAILURE | CAPABILITY | ACCESS | RESOURCE | REQUIREMENT |
INTEGRATION | CONSTRAINT

changes the frontier.

REPEAT UNTIL NO REACHABLE ACTION CAN PRODUCE MATERIAL REPRODUCIBLE NET
ADVANCEMENT.
